> 1. Pengertian, Isi, & Alat Pembuatan Kabel LAN

Panduan lengkap pendahuluan mengenai infrastruktur fisik jaringan komputer.

Apa itu Kabel LAN / Ethernet?

Kabel LAN (Local Area Network) atau sering disebut kabel Ethernet adalah jenis kabel jaringan yang digunakan untuk menghubungkan perangkat komputer satu dengan perangkat komputer lainnya atau perangkat jaringan lain seperti switch, router, dan hub dalam area lokal terbatas. Kabel ini mentransmisikan data dalam bentuk sinyal elektrik antar perangkat.

Penjelasan Isi Kabel LAN (UTP)

Kabel LAN tipe UTP (Unshielded Twisted Pair) umumnya berisi 8 buah kabel kecil dengan warna yang berbeda-beda dan saling berpasangan (twisted pair) untuk mengurangi interferensi elektromagnetik. Kombinasi warnanya meliputi:

  • Putih-Oranye & Oranye
  • Putih-Hijau & Hijau
  • Putih-Biru & Biru
  • Putih-Cokelat & Cokelat

Alat dan Bahan yang Digunakan

Peralatan esensial untuk merakit kabel LAN secara mandiri.

1. Kabel UTP (Cat5e/Cat6)

Media transmisi utama yang berisi 8 konduktor tembaga.

2. Konektor RJ-45

Kepala konektor plastik tempat memasukkan susunan kabel.

3. Tang Crimping

Alat untuk mengunci konektor RJ-45 agar menjepit kabel dengan kuat.

4. LAN Tester

Alat penguji untuk memastikan ke-8 pin kabel terhubung dengan benar.

Cara Pembuatan Kabel LAN (Fokus Tipe Cross-Over)

Kabel tipe Cross-Over digunakan untuk menghubungkan dua perangkat yang sejenis secara langsung (misalnya Laptop ke Laptop). Berikut langkah-langkah pembuatannya:

Langkah 1

Kupas Jaket Kabel

Kupas kulit luar kabel UTP sekitar 2 cm menggunakan pisau crimping untuk mengekspos 8 kabel di dalamnya.

Langkah 2

Susun Urutan Warna

Ujung A: Standar T568A (Putih Hijau, Hijau, Putih Oranye, Biru, Putih Biru, Oranye, Putih Cokelat, Cokelat). Ujung B: Standar T568B (Putih Oranye, Oranye, Putih Hijau, Hijau, dst).

Langkah 3

Crimping & Pengujian

Ratakan ujung kabel, masukkan ke pin RJ-45, jepit dengan tang crimping, lalu tes menggunakan LAN Tester.

Tutorial Lengkap

Panduan lengkap cara menghubungkan 2 laptop, pengaturan IP Address statis, dan sharing file.

Setting IP Address

Agar kedua laptop saling mengenali, atur IP manual di Network Connections:

  • Laptop 1: IP 192.168.1.1 | Subnet: 255.255.255.0
  • Laptop 2: IP 192.168.1.2 | Subnet: 255.255.255.0
Pengecekan (Ping)

Buka aplikasi Command Prompt (CMD) di salah satu laptop untuk menguji koneksi jaringan menggunakan perintah:

ping 192.168.1.2

Jika muncul status Reply from... berarti kedua laptop sudah terhubung dengan sukses.

Cara Transfer File

1. Aktifkan File and Printer Sharing di Control Panel.
2. Klik kanan folder yang ingin dibagikan > Properties > Tab Sharing > Advanced Sharing.
3. Buka File Explorer > Network, akses IP laptop tujuan, lalu salin/tempel file yang diinginkan.
