1. Pengertian, Isi, & Alat Pembuatan Kabel LAN

Panduan lengkap pendahuluan mengenai infrastruktur fisik jaringan komputer.

Apa itu Kabel LAN / Ethernet?

Kabel LAN (Local Area Network) atau sering disebut kabel Ethernet adalah jenis kabel jaringan yang digunakan untuk menghubungkan perangkat komputer satu dengan perangkat komputer lainnya atau perangkat jaringan lain seperti switch, router, dan hub dalam area lokal terbatas.

Penjelasan Isi Kabel LAN (UTP)

Kabel LAN tipe UTP (Unshielded Twisted Pair) berisi 8 buah kabel kecil dengan warna berbeda yang saling berpasangan (twisted pair):

  • Putih-Oranye & Oranye
  • Putih-Hijau & Hijau
  • Putih-Biru & Biru
  • Putih-Cokelat & Cokelat

Alat dan Bahan yang Digunakan

Peralatan esensial untuk merakit kabel LAN secara mandiri.

1. Kabel UTP (Cat5e/Cat6)

Media transmisi utama yang berisi 8 konduktor tembaga.

2. Konektor RJ-45

Kepala konektor plastik tempat memasukkan susunan kabel.

3. Tang Crimping

Alat untuk mengunci konektor RJ-45 agar menjepit kabel dengan kuat.

4. LAN Tester

Alat penguji untuk memastikan ke-8 pin kabel terhubung dengan benar.

Cara Pembuatan Kabel LAN (Fokus Tipe Cross-Over)

Kabel tipe Cross-Over digunakan untuk menghubungkan dua perangkat sejenis secara langsung (seperti Laptop ke Laptop).

Langkah 1

Kupas Jaket Kabel

Kupas kulit luar kabel UTP sekitar 2 cm menggunakan pisau crimping untuk mengekspos 8 kabel di dalamnya.

Langkah 2

Susun Urutan Warna

Ujung A: Standar T568A. Ujung B: Standar T568B untuk membuat konfigurasi silang (cross-over).

Langkah 3

Crimping & Pengujian

Masukkan ke konektor RJ-45, jepit dengan tang crimping, lalu tes menggunakan LAN Tester.

Tutorial Lengkap

Panduan lengkap cara menghubungkan 2 laptop, pengaturan IP Address statis, dan sharing file.

Setting IP Address

Atur IP manual di Network Connections:

  • Laptop 1: 192.168.1.1 (Subnet: 255.255.255.0)
  • Laptop 2: 192.168.1.2 (Subnet: 255.255.255.0)
Pengecekan (Ping)

Buka aplikasi CMD dan ketik perintah berikut untuk menguji koneksi:

ping 192.168.1.2

Status Reply menunjukkan laptop terhubung.

Cara Transfer File

1. Aktifkan File Sharing di Control Panel.
2. Bagikan folder (Advanced Sharing).
3. Akses via File Explorer di menu Network dengan mengetik IP tujuan.
